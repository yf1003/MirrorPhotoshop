# 日常使用

首次在一台新电脑接入时，先完成 [从零接入与 AI 操作指南](03-从零接入与AI操作指南.md)。本篇针对已经构建、安装过的环境。

## 查看已保存的 PSD

1. 在项目根目录双击 `启动Mac端.command`。若没有构建产物，脚本会尝试构建 Mac 应用，需要完整 Xcode 和 Python 3。
2. 在 Mac 应用中点「添加 PSD…」或「添加文件夹…」。文件夹会递归搜索 PSD；当前每次添加最多收集 100 个文件。
3. Mac 和 iPhone 接入能够互通的同一局域网，按系统提示允许 PSD Mirror 的本地网络访问。
4. 手机打开 PSD Mirror，点「扫码连接」，首次使用按提示允许相机访问，对准电脑窗口右上角的二维码。使用的是 PSD Mirror 内置扫描器，不是系统相机 App。
5. 识别后会自动读取连接信息、连接并显示 PSD 列表，点选文件后进入全屏。Mac 重启后重新扫码；不再需要搜索附近 Mac 或填写地址、配对码。
6. 在 Mac 点某个条目的「发送到手机」，或在手机 PSD 列表中自行选择。

Mac 应用需要一直运行。此模式只在 PSD 保存后更新；需要 PSD 带有兼容合成图。若解码失败，在 Photoshop 中开启「最大化 PSD 和 PSB 文件兼容性」后，由使用者确认并重新保存文件。

连接后首页以 PSD 列表为主，显示文件名、尺寸和来源；轻点文件进入全屏。右上角「…」菜单提供跟随 Mac、重新扫码和断开连接。未连接时仅显示上方居中的标题和居中的扫码按钮；连接异常时才显示必要提示。

清理手机列表时，点「管理」，勾选要删除的 PSD 或画板，也可点「全选」，再点「删除」。这只移除本机列表条目，不会删除 Mac 上的原文件，也不会影响其他手机。再次连接时，同一条目仍会隐藏；Photoshop 重新打开文档后生成的新实时条目可以再次出现。需要找回时，从「…」选择「恢复已删除条目」。全屏预览中的 PSD 列表也支持管理。

## 查看 Photoshop 中未保存的修改

1. 保持 Mac 应用运行。
2. 启动 Photoshop，用 Adobe UXP Developer Tool 加载 `PhotoshopPlugin/manifest.json`。开发加载的插件在 Photoshop 重启后可能需要重新加载。
3. 在 Photoshop 的「增效工具 → PSD Mirror」打开面板。插件自动连接本机 Mac 应用并开始同步；如果此前明确暂停过，点「开始实时同步」。无需选择文件夹或填写路径。
4. 打开已经以 `.psd` 命名的文档。确认插件显示「已同步」，Mac 底部显示「Photoshop 已连接」，手机列表出现来源为「Photoshop 实时」的条目。
5. 在手机列表右上角「…」菜单开启「跟随 Mac 当前画面」。进入预览后，编辑、撤销或切换 PSD 时自动发送新画面，不需要保存原始 PSD。

插件面板采用简洁布局，仅保留「PSD Mirror」标题、清晰度选择、「开始实时同步／暂停同步」、「立即发送当前画面」按钮和动态状态。已移除「在 iPhone 上实时查看当前 PSD」「只读画面，不会保存或修改你的 PSD」「自动连接本机 Mac 端 PSD Mirror」三行固定说明；自动连接和只读预览的行为保持不变。

保持插件面板打开。关闭面板会暂停；重新打开会恢复此前开启的同步。明确点「暂停同步」后则不自动恢复。PSD 原文件不会被本项目自动保存或改写。Mac 尚未启动或之后重启时，插件会自动重试连接。

多画板 PSD 实时同步后，手机列表按画板分开显示，画板名称下方是所属 PSD。点某个画板即可全屏查看。开启「跟随 Mac 当前画面」时，手动点选画板后仍可跟随：在 Photoshop 图层面板选另一个画板，或选中它里面的图层，手机就会切过去。想固定看一张画板时，关闭跟随。新增、改名和删除画板无需保存即可同步。每个 PSD 最多同步 64 个画板；如果大图超过预览缓存容量，可降低插件清晰度并重新发送。

`加载Photoshop插件.command` 是当前机器已准备好旧版 Adobe CLI 工具时的快捷入口。GitHub 源码不包含这些下载工具；新电脑应按接入指南使用 Adobe 官方 UXP Developer Tool，不能假定双击该脚本即可完成首次安装。

## 手机全屏操作

轻点画面显示或隐藏工具栏，工具栏在约 4 秒后自动隐藏。双指缩放、拖动，双击放大或回到适应屏幕。工具栏依次包含：返回、PSD 列表、适应屏幕、铺满屏幕、1:1、切换背景。

- **适应屏幕**：显示整张图；长宽比不同时会有留白。
- **铺满屏幕**：覆盖整个显示区域，超出部分可以拖动查看。
- **1:1**：按 PSD 原稿像素与设备物理像素对应；不是一个原稿像素对应一个 UIKit 点。若传输前缩小了图片，细节仍受传输分辨率限制。

预览使用原生界面，隐藏状态栏和工具栏，支持横竖屏，并在预览期间保持屏幕常亮。iOS 自身的相机开孔及系统手势区域仍遵循系统行为。

## 常见问题

| 现象 | 检查或处理 |
| --- | --- |
| 扫码后仍连接不上 | 检查 Mac 是否运行、两端本地网络权限和 Wi-Fi；部分访客 Wi-Fi 或公司网络隔离设备，二维码不能绕过网络隔离 |
| 提示二维码失效 | 扫描正在运行的 Mac 窗口中的新二维码，不要使用上次启动的截图 |
| 扫码界面提示相机未开启 | 在手机系统设置中允许 PSD Mirror 使用相机，再重新扫码；无可用相机的模拟器不能完成实际扫码 |
| 手机看到旧 PSD | 检查来源，选「Photoshop 实时」条目，开启手机跟随；确认 Mac 当前选择没有停在另一张已保存 PSD |
| 插件一直等待 Mac | 确认同一台电脑的 Mac 应用已启动，Mac 状态未提示插件端口占用；核对两边使用的都是当前版本 |
| 移动项目后同步失效 | 从新位置启动 Mac 应用，并重新加载新位置的插件；无需重新选择目录 |
| 插件提示 modal scope | 截图调用必须处于 `executeAsModal` 内；现有代码已处理，确认加载的是本仓库当前版本，见开发文档 |
| 安装成功但 iPhone 拒绝首次启动 | 按 iOS 提示信任本人开发者证书；查看设备管理和开发者模式状态 |
| 几天后手机应用打不开 | 检查本人的签名描述文件有效期，重新签名安装，见接入指南 |

仅通过可信局域网连接。当前服务采用带配对码的 HTTP，未实现 TLS；不要配置公网端口映射。
